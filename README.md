# 🚀 SpaceRocket - Telegram Idle Game

![Tech Stack](https://img.shields.io/badge/Stack-React%20Vite%20%7C%20Node.js%20%7C%20MongoDB%20%7C%20Docker-brightgreen)
![Telegram Integration](https://img.shields.io/badge/Integration-Telegram%20Bot-blue)

Игра кликер внутри Telegram с механикой автоматического сбора ресурсов, улучшениями и системой достижений. Игроки открывают новые планеты, покупают улучшения и соревнуются в рейтингах.

## 🌟 Основные возможности

### 🕹️ Игровой процесс
- **Кликер**: возможность кликать на кнопку добычи коинов
- **Система улучшений** ⬆️:
    - Покупка предметов с проверкой уровня и валюты
    - Визуализация улучшений (иконки стрелок)
    - Прогрессивная стоимость предметов
- **Планетарная система** 🪐:
    - Динамическое изменение размера планеты при получении опыта
    - Визуальные эффекты (взрывы при разблокировке)
    - Система блокировки/разблокировки планет
- **Автоматический бот** 💻: Возмоности некоторый предметов - начисление монет после отсутствия (5-минутный кулдаун)

### 📊 Социальные функции
- **Таблица лидеров** 🏆:
    - Сортировка по уровню, опыту, монетам, а так же количеству планет и предметов
    - Показ аватаров и прогресса игроков
- **Прогресс игрока** 📈:
    - Уровневая система с опытом
    - История транзакций

### 🤖 Интеграция с Telegram
- 🔐 Авторизация через Telegram User ID
- 📱 Оптимизация для мобильных устройств
- 🛡️ Защищенные маршруты для авторизованных пользователей

## 🛠 Технологический стек

### Backend (Node.js)
- **Модели данных**:
    - `UserModel`: Профиль игрока, прогресс
    - `GameModel`: Состояние игры, таймстампы
    - `ItemModel`: Магазин улучшений
    - `TransactionModel`: История покупок, улучшений, разблокирования
    - `PlanetModel`: Планетарий
- **API**:
    - RESTFull endpoints для игровых операций
    - Сложные MongoDB-запросы для лидерборда


### Frontend (React Vite)
- **Ядро**: React + Redux (управление состоянием)
- **Компоненты**:
    - `Rocket.jsx` - анимированная ракета с эффектами частиц
    - `CoinsDisplay + LevelDisplay` - управление сотоянием монет и уровня во всех уголках приложения 
    - `Planet.jsx` - интерактивная 3D планета
    - `LeaderBoard.jsx` - таблица лидеров с сортировкой
- **Стили**: CSS-in-JS с анимациями


### Инфраструктура
- 🐳 Docker + Docker Compose
- 🍃 MongoDB с индексацией
- 📊 Логирование и мониторинг
- 🔄 Автоматические бэкапы
